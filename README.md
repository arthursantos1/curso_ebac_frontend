# curso_ebac_frontend
<p>Exercícios do curso da Ebac</p>
<p>Exercício proposto no modulo 12 - Bootstrap Avançado</p>
<p>A entrega consiste nos seguintes criterios:</p>
<ul>
  <li>Criar um projeto utilizando o Bootstrap</li>
  <li>Criar uma página que contenha os elementos</li>
  <li>Carousel de imagens</li>
  <li>Um layout com grid, onde na visão desktop teremos 3 itens por linha, no tablet 2 itens por linha e no smartphone 1 item por linha</li>
  <li>Inserir um card dentro das colunas, o conteúdo do card fica a seu criterio</li>
  <li>Publique o projeto na Vercel</li>
  <li>Enviar o link através da plataforma da EBAC</li>
</ul>
<hr>
<p>Nesse exercício eu criei uma página inspirada no prime vídeo, no projeto ele não possui todas as funcionalidades iguais ao site porém foi adicionado todos os estilos conforme orientado no execício e também ao que o Bootstrap pode fornecer</p>
