<h1>Recursos ES6+</h1>
<p>Exercício do módulo 25 do Curso da EBAC</p>
<p>Neste exercicio foi colocado em práticas alguns recursos do ES6 como buscar em array e criação de Array de objeto</p>
<p>A entrega do exercício consiste:</p>
<ul>
  <li>Cria um array de objetos, onde teremos como atributos do objeto: o nome e a nota de alunos;</li>
  <li>Criar uma função que irá retornar apenas os alunos que tiveram a nota maior ou igual à 6;</li>
  <li>Crie uma branch exercicio_es6 no repositório do curso, armazene o código nesta branch e nos envie o link através da plataforma.</li>
</ul>
<p><strong>Fora realizado o que foi exigido foi utilizado o Babel no exercicio para fins de treinamento da ferramenta</strong></p>
