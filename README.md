<h1>Exercicio de Teste Cypress</h1>
<p>No que consiste este exercicio</p>
<ol>
  <li>Criar um projeto de testes utilizando o Cypress;</li>
  <li>No script de testes você deverá testar as funcionalidades da aplicação disponivel no link: https://ebac-agenda-contatos-tan.vercell.app</li>
  <li>Testar as funcionalidade:</li>
    <ul>
      <li>Inclusão;</li>
      <li>alteração</li>
      <li>remoção de um contato;</li>
    </ul>
  <li>No repositorio do curso, criar uma branch chamada exercicio_cypress;</li>
  <li>Armazenar nessa branch o conteúdo do projeto de teste;</li>
  <li>Enviar o link do repositorio através da plataforma</li>
</ol>
